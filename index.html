🔐 Hak Akses

Atur fitur yang boleh dipakai tiap role. Super Admin selalu punya akses penuh. Perubahan langsung berlaku di semua perangkat yang tersambung ke server ini.

🖨️ Printer Bluetooth Thermal

Cetak struk 58mm langsung ke printer (XPrinter / RPP02 / sejenis) via APK Android. Pairing dulu di Settings HP → Bluetooth, lalu Scan di sini.

Status⏳ mengecek...

Di browser laptop: tombol 🖨 tetap pakai print biasa. Di APK + printer tersambung: nota otomatis keluar via Bluetooth.

🔌 Backend Server (FastAPI)

Status koneksi ke server Ubuntu + database. Hijau = tersambung, merah = offline (pakai LocalStorage).

Status⏳ mengecek...

Di server Ubuntu jalankan sudo ./deploy/deploy-ubuntu.sh, lalu buka http://IP-SERVER/. Bisa juga override cepat via URL: ?api=http://IP:8000. Detail: DEPLOY-UBUNTU.md.
